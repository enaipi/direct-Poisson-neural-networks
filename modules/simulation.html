Simulation (dpnn.simulation)¶

The simulation module contains trajectory simulation engines and CLI interface for generating trajectories with different models.

Simulator (simulator)¶

Contains core simulation functionality including: - simulate_batch(): Simulate trajectories in batch - save_simulation(): Save simulation results - Physics solvers for different mechanical systems

dpnn.simulation.simulator.save_simulation(data_frame, file_name)¶

The function save_simulation saves a data frame to a file with the specified file name.

Parameters:

  • data_frame – A pandas DataFrame containing the simulation data that you want to save to a file

  • file_name – The name of the file where the data will be saved

dpnn.simulation.simulator.simulate_batch(args, initial_states_batch, method='normal')¶

CLI Interface (simulate)¶

Command-line interface for generating trajectories. Accessible via the simulate console command.

Example Usage¶

Generate training dataset:

simulate --generate --steps=50000 --model=RB

Generate test trajectories:

simulate --steps=500 --generate
simulate --steps=500 --implicit
simulate --steps=500 --soft
simulate --steps=500 --without

View available options:

simulate --help

Supported Models¶

  • RB: Rigid Body

  • HT: Heavy Top

  • P3D: Particle in Three Dimensions

  • P2D: Particle in Two Dimensions

  • K3D: Additional 3D model
